# 0.3.0 验证说明

## 交付范围

这是 Harness 插件 0.3.0 正式版；QPM Python Core 0.1.0 仅作为插件 ZIP 内部运行依赖，不单独发布。程序与安装验收面向 Windows 桌面 Harness 0.2.0-rc.2。

## 当前验证结论

- 插件已实现的 Skill、工具调用、任务规范化、预算约束、演示工作流、结果访问/绘图、扩展审核及安装流程完成初步验收。
- 代表性物理检查通过；适用范围见插件能力目录和 Core 随包验证目录。该结论不等同于任意材料、晶向、几何及全部非线性过程的科学认证。
- 插件当前能力范围外的语义任务，以及更完整的自主研究流程属于后续版本扩展范围；此版本不宣传为通用任意设计 agent。
- 0.3.0 未修改求解器或物理模型，因此不重复运行COMSOL科学试算或付费模型评测。
- 安装包的 PS 5.1 / PS 7 隔离 desktop-profile 验收只在 `dist/INSTALLER-ACCEPTANCE.json` 绑定同一最终ZIP SHA256后，才可视为该ZIP的安装验收通过。

## 手工复核

发布前执行完整 `python dev/release.py`，检查版本、插件预编译文件、tgz、wheel、清单和ZIP一致性，并完成Windows 5.1/7安装回归。Release上传后核对Git tag目标、正式发布状态和每个下载附件的哈希。运行结果应记录到该版本的发行记录；不可沿用dev.10或0.2.0的ZIP哈希回执。

本页不记录个人机器许可证、COMSOL模型尺寸或网格求解参数。验证状态不宣称完成其他Harness版本、其他OS或完整自主研究闭环验证。
