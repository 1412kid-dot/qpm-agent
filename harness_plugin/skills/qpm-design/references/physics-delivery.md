# 物理表述与交付

计算结束后读取 qpm_status 的 delivery；历史任务可用 qpm_delivery 获取完整事实摘要。对话交付请求指标、数值和单位、数据来源、验证状态及结果和过程报告链接。曲线摘要保留有效点数量和范围；容差任务覆盖名义结构及各偏差端点。详细过程来自研究事件，可用 qpm_process 分页读取。

用 qpm_conventions(topic=wavelengths) 查询版本化公式。beta=2*pi*n_eff/lambda_vac；delta_beta=sigma_h*beta_h-sigma_1*beta_1-sigma_2*beta_2。方向符号不是公式里的减号。K_m=2*pi*m/Lambda；匹配剩余量为 delta_beta-K_m。m 的符号与光栅补偿方向一致；正周期为 2*pi*abs(m)/abs(delta_beta)。delta_beta=0 是自然相位匹配条件，不能报零周期。

固定方向交换低频偏振：同向简并的和不变；反向简并及同向非简并一般改变。完整交换波长、模式、方向的标签只是重命名。任何额外结论都应说明条件及证据，不能由“简并”直接推断交换不变。

上述不变性不涵盖每一路的 beta1_j=d beta_j/d omega_j。相同非零 |m| 下，两个有限正周期相等的充要条件是 |delta_beta_A|=|delta_beta_B|，包括符号相反的情形。50% 占空比下非零偶数阶的傅里叶系数为零，不能说 K_m 为零；其他占空比可能支持偶数阶。

solver_calls 是实际求解计数，cache_hits 是另外的缓存读取计数，两者不能互相替代。追加 GVD/GVM 等导数指标后重新估算预算。失败原因只报告日志或模式筛选记录支持的事实；非默认模式、低 overlap 或有限峰值偏移本身不能确定弱束缚、非基模或某一路失败。

独立 Lumerical 基准在开发验收、相关模型变更后运行；日常任务不自动重跑。它只验证记录中的结构、模式和指标。数值收敛、达到设计目标和跨求解器物理对照分别报告。Skill 指导何时调用和解释检查，参考数据与执行器提供检查证据。
