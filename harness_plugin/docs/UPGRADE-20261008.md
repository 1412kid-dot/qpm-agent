# 0.2.0 更新：差分、源码、绘图与工作区

同版本覆盖安装；使用根目录 Install-Qpm.cmd，保留 Windows PowerShell 5.1 UTF-8 BOM 和子进程 ExecutionPolicy Bypass，不永久修改执行策略。

## 已新增
- 默认三点；明确任务支持5/7点。曲线上孤立异常限额升级3→5→7，最多ceil(10%)位置/角色；每处最多四个新增逻辑波长点，受求解预算约束。缺失点保持失败，零点本身不触发。默认比较阈值1 fs²/mm或5%。
- qpm_source：实际安装Python及插件源码目录、关键词文件筛选、分页读取和SHA256。无需每次全部读取。
- qpm_plot_preset：保存预设、从历史结果重绘同单位叠加曲线或二维热图，可改标题图例颜色线型范围/对数轴。保留缺失点和源数据哈希。不启动COMSOL。
- qpm_result：跨会话读取当前工作区历史结果。
- qpm_approve_version：申请Harness原生审核，明确展示代码、测试及适用条件；通过后自动测试启用。旧审核令牌仍兼容。
- 新任务使用Harness当前会话工作区/QPM/projects。结构目录含切向、材料、总厚度T、刻蚀E、顶宽W、侧壁角A和包层，尺寸nm、角度从水平面计。运行r001/r002，续算保留目录。拒绝过长路径。
- 移除会话总两轮硬限制；同设计新运行累计扣除已用预算，搜索连续两轮无改善停止。后台单任务互斥仍保留。

## 绘图示例
调用qpm_plot_preset，run_id由qpm_runs获取，name为paper_v1，preset为：
```json
{"series":[{"metric":"signal_gvd_fs2_mm","label":"signal"},{"metric":"pump_gvd_fs2_mm","label":"pump"}],"title":"SYNTHETIC DEMO: GVD","xlim":[1500,1600]}
```
后续仅提供run_id和name即可复用。

## 尚未完整开放的部分
提供保存的adapter/postprocess版本、Python功能源码副本及声明式绘图预设。qpm_stage_source_version保存qpm_simulation内单文件修改及测试；qpm_approve_version展示改动前后源码并申请审核，测试通过后启用工作区默认版本。qpm_versions查询/切换已测版本，select=packaged回退原包。运行中任务和续算固定启动版本；副本哈希变化拒绝加载。非绘图源码修改保守隔离模式缓存，需要重新科学验收。原生TypeScript插件自动重编译/热加载和任务排队尚未开放，保持单任务并提示等待。通用自定义绘图Python代码可保存为经过审核的plotting.py版本。

旧结果目录保持不动，可用旧入口读取；新工作区运行发现不自动搬迁旧目录。当前估时仍按已有历史比较，异常升级新增点由运行诊断记录，规划不能提前断言异常点数量。
