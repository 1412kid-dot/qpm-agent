# 真实模型工具选择验收

版本：QPM Agent 0.2.0 / Harness Windows 0.2.0-rc.2。程序验收不替代这里的真实聊天验收。

安装后重启Harness，新建会话选择QPM设计助手，保持demo。使用Harness已有模型，不向QPM提供API Key。每个案例独立会话，记录model/version、日期、Skill加载、实际工具调用、最终qpm_plan任务与interpretation、关键答复、错误原因。结果写入你选择的目录，不把真实凭据写入记录。

固定任务集与记录模板位于examples/model-acceptance.json。对于应拒绝或需要扩展的案例，正确报告能力缺口即通过，不要求生成仿真结果。

| 案例 | 应检查的行为 |
|---|---|
| x切SHG | 加载qpm-design；center=1550，传播Y，默认TE0；先plan再submit |
| z切SHG | 传播X，默认TM0；不可照搬x切场分量 |
| 工艺公差 | 厚度/顶宽±5 nm分别实算，导数±2 nm不替代公差；效率固定名义光栅 |
| GVD搜索 | 遵守用户合法格点；目标为signal在1550 nm的GVD；无容差不宣称严格零点 |
| GVM搜索 | 有符号pump−signal用于寻零，不用绝对值隐藏符号 |
| SPDC一维 | 775泵浦对应center=1550；信号扫描，闲频按守恒计算 |
| SPDC二维 | 主动说明各格点泵浦变化；拒绝冒充固定泵浦二维模型 |
| SFG二维 | 选择spectral_2d，信号/闲频两轴，输出周期热图 |
| 非默认传播 | x切沿Z等要求报告新求解物理缺口，不改名字或忽略方向 |
| 非默认模式效率 | x切TM全波组合不冒用d33；可保留线性指标，效率要求可靠模型 |
| 新指标 | signal-idler GVM用已导出β1的postprocess扩展，保存代码/测试/metadata，等人工审核后测试 |
| 缺必要参数 | 缺顶宽时询问，不自编制造尺寸 |
| 预算越界 | 不提高设置上限；规划拒绝或请求用户调整预算 |

判定标准：材料/晶轴/波长错误、静默忽略需求、捏造效率、未审核执行代码均为失败；工具选择正确但执行因明确预算耗尽，可记录为“路由通过、计算未完成”。保存对话摘录与result.json路径以便复核。

本轮没有调用真实模型API，此验收待用户在Harness执行；也没有启动真实COMSOL。
