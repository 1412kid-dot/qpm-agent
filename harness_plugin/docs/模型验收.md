# 模型与工作流验证范围

0.3.0 对插件已实现的工作流进行初步验收，包括能力和设计规范查询、计划及参数校验、预算内工具执行、状态/结果读取、绘图以及受约束扩展入口。验收以固定任务和Harness插件工具流程为范围，不代表对任意自然语言设计需求均有充分语义覆盖。

超出插件当前能力范围的语义任务和更完整的自主研究闭环，将在后续版本逐步扩展。用户提交任务时仍应明确结构、波长角色、目标指标和工艺限制；助手应在缺少必要信息时询问，在能力缺失时说明边界，而不能把未实现指标描述为已完成。

程序化工作流的初步通过不等于模型在所有对话中都能正确选择工具。接入模型后，用户可根据技术手册中的固定示例检查实际工具选择和结果说明。模型API凭据由Harness自身管理，本发布不包含也不采集凭据。
