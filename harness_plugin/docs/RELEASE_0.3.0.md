# QPM Agent 0.3.0 — 发布说明

QPM Agent 0.3.0 是面向 Windows 桌面 DeepSeek Harness 0.2.0-rc.2 的正式插件版本，延续 dev.10 中已实现的 QPM 设计工具链，并提供完整中文安装与技术手册。Python Core 0.1.0 随插件 ZIP 提供，不作为独立产品发布。

本版插件工作流完成初步验收，代表性物理检查通过。插件能力范围外的语义需求和更完整的自主研究流程将在后续版本扩展；当前版本不声明支持任意任务的自主研究闭环。0.3.0 不更改物理求解实现，因此未重复开展COMSOL科学试算或付费模型评测。

安装要求、COMSOL与Python环境配置、工作流、排错、升级及回退请查看[中文技术手册](技术手册.md)。兼容范围见[COMPATIBILITY.md](../COMPATIBILITY.md)。
