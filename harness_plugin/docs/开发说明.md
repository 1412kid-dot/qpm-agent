# 开发说明

## 组件与职责

src/index.ts是共享qpmRuntime服务，管理Python子进程、任务所有权、全局串行、轮数、配置快照、超时和独立扩展。src/tools.ts通过官方defineTool注册12项工具。src/skill.ts使用原生skills.register注册打包规范，preset加入官方dsh-tool-skill。src/config.ts定义可编辑配置，src/client.ts导出原生设置卡片。cordis.patch.yml声明服务和可选preset-qpm，不改默认预设。

Python通过`python -u -m qpm_simulation.harness_worker`接收一条JSON请求，stdout只输出qpm/1 NDJSON进度、结果、错误，其他日志去stderr。执行中的取消采用任务目录.cancel标记和Harness管理的进程范围终止，避免Windows管道读取线程锁。摘要保留前三个曲线点、验证状态、成本与路径，完整场数组留磁盘。

源码为TypeScript可接受的JavaScript子集，构建直接生成ESM，不做类型检查；无安装时编译步骤。SDK接口依赖在本机随附ASAR中核对。dev/extract-sdk.cjs只提取SDK到开发测试目录；提取内容不打进发布ZIP。dev/native-smoke.mjs使用真实Cordis、子进程范围管理和后台任务服务调用工具，无模型API。

## 本地开发与打包

```powershell
node dev/extract-sdk.cjs
python dev/generate-contract.py
node dev/build.cjs
node --test tests/*.test.mjs
node dev/native-smoke.mjs
# 在AUTO_Simulation目录构建wheel；Python应有setuptools>=68
python -m pip wheel . --no-deps --no-build-isolation --wheel-dir harness_plugin/dist
# 在harness_plugin目录
python dev/pack.py
python dev/release.py
```

测试脚本当前包含本机解释器路径，跨机器需修改测试配置；发行插件/安装脚本不依赖该路径。Python功能回归用AUTO_Simulation中的pytest，原代码哈希用verify_original_hashes.py。真实COMSOL试算使用原有显式CLI，不由导入、环境检查或计划启动。

## 配置与扩展约束

任务字段通过prepareTask补默认并拒绝超过上限的任务。用户显式comsol_bin不能绕过设置路径。每轮记录配置快照。模型工具没有设置写接口、通用shell或文件覆盖接口。新扩展将代码+测试+规范化metadata一并哈希；兼容旧无metadata令牌。必须人工批准并测试，通过后才能适配任务或分析结果。类型、哈希、测试、会话所有权与预算均重新检查。

规范依据qpm_simulation/conventions.py和task_schema.py，release首先运行generate-contract.py，生成Skill晶轴表、schema、模板和规范JSON。工具将标准JSON Schema转换为Harness参数DSL；数值与物理限制仍在Python中校验。不能独立改生成的JSON作为新物理能力。传播方向字段只允许x切Y、z切X；required_metrics在校验、计划和执行时拒绝未实现输出。公开Python入口describe_conventions/task_schema及CLI conventions/schema不启动求解器。

初版没有恢复运行中任务、UI图表浏览、模型聊天自动验收、非Windows兼容、类型检查或任意求解器扩展自动装载；这些不能被文档或LLM称作已完成。API和COMSOL许可证均由用户部署环境管理。

## 开源准备

选择许可证、整理第三方来源/非线性与材料模型适用性说明、补跨平台CI与真正模型集成验收，再创建公共仓库。现交付为本地可安装发行包，不替作者擅自授予既有代码的开源许可证。

## desktop安装校验

profile-helper.cjs通过桌面Electron-as-Node调用安装内官方loadProfileDirectory/composeEntries，并用官方配置Schema检查QPM参数；不调用prepareProfile（会写root文件），不执行!!js，不挂载模型/求解服务。Qpm-Common.ps1用于安装、检查、卸载和恢复，限制pnpm自动安装peer依赖以复用随附SDK；退出后恢复环境变量。profile写入使用官方文件锁、内容哈希冲突检查和原子替换。installer验收入口是dev/installer-acceptance.py，从发布ZIP解压后在隔离desktop profile运行。
