# 使用说明

QPM Agent 0.3.0 的安装、Python/COMSOL环境准备、Harness配置、任务模板、历史结果、绘图、续算和故障排查已合并到[中文技术手册](技术手册.md)。

快速路径：准备64位 Python 3.12+和科学计算依赖 → 退出 Harness → 解压完整Windows ZIP → 从根目录运行 `Install-Qpm.cmd` → 重启 Harness → 先用 demo 后端调用 `qpm_capabilities`、`qpm_plan` 和示例任务 → 通过环境检查后再显式启用 COMSOL。

当前首个兼容目标为 Windows 桌面 Harness 0.2.0-rc.2。COMSOL与许可证、Python桥接、模型API凭据由使用者自行准备；插件不附带这些内容。
